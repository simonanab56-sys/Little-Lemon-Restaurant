# 🍋 Little Lemon Restaurant SPA

 Live Demo: https://astounding-haupia-c418ef.netlify.app  
 GitHub: https://github.com/simonanab56-sys/Little-Lemon-Restaurant  

A modern, responsive restaurant web application built with React and Vite, featuring menu browsing, reservations, and a smooth user experience.



##  Features

- Modern React SPA with React Router  
- Responsive design (mobile-first)  
- Three main sections:
  - Home (Hero, Featured Dishes, About, Testimonials)
  - Menu (categorized with filtering)
  - Reservation system with Stripe payment integration  
- CSS-only styling (no frameworks)  
- Performance optimized for low-bandwidth networks  
- Real-time form validation  
- Secure payment processing (Stripe)  
- Toast notifications for user feedback  
- Smooth animations and transitions  
- SEO-friendly structure  



##  Tech Stack

- React 18.3.1  
- Vite 6.3.5  
- React Router 7.13.0  
- Stripe (Payment Processing)  
- Lucide React (Icons)  
- Sonner (Toast notifications)  
- Standard CSS (Mobile-first design)
